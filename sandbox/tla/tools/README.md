# TLA+ tools downloads

The original TLA+ tools distribution is available from:

- Microsoft Download Center: https://www.microsoft.com/en-us/download/details.aspx?id=52467
- Leslie Lamport's TLA+ tools page: https://lamport.azurewebsites.net/tla/tools.html

If needed, download and extract the distribution into `tools/tla` under the TLA sandbox directory.

These tools are optional. The `diehard-rust` project uses `tla-checker` and its own copies of the DieHard model, so it does not require this distribution or Java.
