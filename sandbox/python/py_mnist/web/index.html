What happens between drawing and guessing?

  1. Prepare the pixels. Crop the ink, fit it inside 20 × 20 pixels, and center it by its pixel mass on a black 28 × 28 image.
  2. Run the network. Send 784 values between 0 and 1 through the same 784 → 128 → 10 model trained in Python.
  3. Read the scores. Apply softmax to the ten output logits. The largest score is the predicted digit.

Scores are not a guarantee. A confident model can still be wrong, especially when your drawing looks different from MNIST. The network always chooses among digits, even for a doodle.

Prediction runs on your device using WebAssembly. Your drawings are not uploaded. The runtime downloads from jsDelivr; the model loads from this site.
