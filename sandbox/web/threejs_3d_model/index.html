05INSIDE THE LOOP
THE METHOD
01 / GET MOVING

Build energy

At rest, the pendulum hangs down. The cart moves under it to add energy until it can reach the top.

E = ½mL²θ̇² + mgL cos θ
02 / HAND OFF

Catch it upright

Near upright, with manageable speed and room on the rail, control switches from swing-up to LQR.

|θ| < 0.27 rad  ·  |θ̇| < 2.5 rad/s
03 / STAY THERE

Close the loop

LQR weights four states: position error and cart velocity, pole angle and angular speed. Raise a priority to penalize that state more; raise effort penalty to use less force.

u = −K[x−x*, ẋ, θ, θ̇]ᵀ
MODEL NOTE Point-mass pendulum, massless rod, motor force saturation, and a finite rail. LQR is computed around upright, so it is a local controller rather than a guarantee for every starting angle.
